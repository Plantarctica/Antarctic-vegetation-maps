# Plantarctica

JavaScript code for Sentinel-2 derived maps of green vegetation and lichens in ice-free areas and green snow algae in coastal snowpacks across the entire Antarctic continent, maritime islands and archipelagos south of 60 degrees South. These maps were created in Google Earth Engine using Level-2A data, further processing was carried out in QGIS. These maps are presented in the paper 'A satellite-derived baseline of photosynthetic life across Antarctica', published in Nature Geoscience.

Citation: 
Walshaw, C. V., & Gray, A. (2024). Plantarctica/Antarctic-vegetation-maps: GEE code. Zenodo. https://doi.org/10.5281/zenodo.11264049
