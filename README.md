# Plantarctica

JavaScript code for Sentinel-2 derived maps of green vegetation and lichens across ice-free areas and green snow algae across coastal snowpacks in Antarctica. These maps were created in Google Earth Engine, further processing was carried out in QGIS.

Citation: 
Walshaw, C. V., & Gray, A. (2024). Plantarctica/Antarctic-vegetation-maps: GEE code. Zenodo. https://doi.org/10.5281/zenodo.11264049
